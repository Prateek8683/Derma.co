Privacy Policy

1. Overview: This page contains placeholder privacy disclosures for the Derma.co (Derma-Scan) project. Before public deployment, review and adapt this policy with qualified legal counsel.

2. Image Processing on Derma-Scan: When you select or capture an image on scan.html, check the consent box, and click "Analyze Skin Image", your image file is transmitted via an HTTP POST request (multipart/form-data under field file) to the configured backend server (by default http://127.0.0.1:8000/predict) so the model can compute a screening prediction.

3. Browser Storage: The Derma.co frontend does not store your uploaded skin photos or screening outputs in browser localStorage or sessionStorage. Temporary preview URLs created with URL.createObjectURL() are revoked when you remove the image or reset the scan.

4. Backend Retention: How images are handled on the server depends on the configured FastAPI backend implementation. Users should avoid uploading photos containing identifiable faces, name tags, or sensitive personal metadata unless required.
