# Derma.co
Derma-Scan is a deep learning backend for real-time skin lesion segmentation. It uses Google Derm Foundation embeddings, an RTX 5050-optimized pipeline, and an async FastAPI server. Parallel preprocessing and atomic .npz shards ensure speed and reliability, reaching 72.5% Top-1 and 89.3% Top-3 accuracy across 20+ conditions.
